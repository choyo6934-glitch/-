# aoa_research — 워뇨띠(BitMEX `aoa`) 체결내역 규칙 추출·백테스트

연구 기록이며 투자 조언이 아니다. 실거래 주문은 하지 않았다.

| 파일 | 내용 |
|---|---|
| [`REPORT.md`](REPORT.md) | 한국어 보고서: 가정 → 요약 → 검증 → 추출된 규칙 → 규칙집 → 백테스트 표 → 실패 목록 → 한계 |
| [`PREREG.md`](PREREG.md) | 결과 계산 전에 고정한 분할·합격 기준·비용·체결 가정(커밋 `0fb5e8f`) + 변경 기록 |
| [`RULEBOOK.md`](RULEBOOK.md) | 규칙집 A(코인 선물 롱·숏)·B(코인 현물 롱)·C(주식·ETF 롱), 봉인·표본 외 실행 전에 고정(커밋 `17bd00f`) |
| `results/` | 결과 CSV·JSON. `experiment_log.csv`에 시도한 모든 설정과 가설(실패 포함) |
| `src/` | 코드(실행 순서는 REPORT.md 9절) |
| `fetch_inputs.sh` | 입력 데이터 준비(원자료는 공개 원본에서 받아 해시 확인) |
| `data/005930.KS.csv` | 삼성전자 일봉(Yahoo, 2026-11-10 수집) |
| `dist/aoa_research_bundle.zip` | 코드·결과 CSV·기준 문서 묶음(원자료 제외) |

원자료(aoa 체결·지갑 CSV)는 공개자의 요청(직접 분석은 허용, 2차 상품·매매봇 판매 자제)에 따라 이 저장소와 zip에 넣지 않았다.

**결론**: 규칙집 3종 × 자산 8개 조합 모두 사전 고정 기준 불합격. 따라 하기 절차는 제공하지 않는다.
