## 열 정의

### `{symbol}_1h.csv` (klines)

| 열 | 설명 |
|---|---|
| `open_time` | 봉 시작 시각 (UTC ISO-8601, ms) |
| `open`, `high`, `low`, `close` | 시가·고가·저가·종가 (USDT) |
| `volume` | 거래량 (기초자산 수량) |
| `close_time` | 봉 종료 시각 (UTC ISO-8601, ms, `open_time + 1h - 1ms`) |
| `quote_volume` | 거래대금 (USDT) |
| `count` | 체결 건수 |
| `taker_buy_volume` | 테이커 매수 거래량 (기초자산) |

원본의 `ignore` 열(항상 0)은 제거했다.

## 변환 규칙

- **열 이름 통일**: 헤더가 있는 파일은 헤더를 정규 열 이름과 대조해 검증하고, 헤더가 없는 파일은 열 개수를 검증한 뒤 같은 정규 열 이름을 붙였다.
- **타임스탬프 단위**: 값의 자릿수로 판별한다 (`>= 10^15` → µs, `>= 10^12` → ms). 모든 값을 µs로 맞춘 뒤 UTC ISO-8601 문자열(`YYYY-MM-DDTHH:MM:SS.sssZ`)로 변환했다. µs 파일의 `close_time`(`…59.999999`)은 ms로 내림해 ms 파일과 같은 `…59.999`로 기록했다 (내림한 값 340,637개). 그 밖의 시각에 ms 미만 자릿수가 있으면 잘리지 않도록 스크립트가 오류로 중단한다.
- **숫자 값**: 원본 문자열을 그대로 기록했다 (부동소수점 재포맷 없음). 따라서 같은 열에서도 `7225`와 `7225.00`처럼 소수 자릿수 표기가 다를 수 있다.
- **중복 제거**: 같은 `open_time`(펀딩은 `calc_time`)이 여러 번 나오면 먼저 나온 행(이른 월 파일)을 남긴다. 값이 숫자로 같으면 '동일 중복', 다르면 '충돌 중복'으로 집계한다.
- **범위 밖 행**: 요청 기간 밖의 행은 제외하고 개수만 집계한다.
- 각 zip은 같은 경로의 `.CHECKSUM`(SHA256)과 대조해 검증했다.
